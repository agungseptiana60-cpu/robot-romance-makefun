One original pickup line for a robot or an AI (98 characters, verified by running `main.ts` locally): "You must be my loss function, because being near you is the only time my error ever drops to zero." The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
